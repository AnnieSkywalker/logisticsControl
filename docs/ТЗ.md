# Техническое задание: заявки на отгрузку

## 1. Цель

Веб-система для оформления и учёта отгрузок. Водитель заполняет публичную форму
**«Заказ на отгрузку»**. Администратор видит все заявки, корректирует и удаляет их,
управляет справочниками и фильтрует/экспортирует заявки.

## 2. Роли

- **Водитель** — публичная форма без входа.
- **Администратор** — вход по email + пароль + 2FA, доступ к `/admin`.

## 3. Форма «Заказ на отгрузку» (публичная, секция на `/`)

| Поле | Тип | Обязательное | Источник |
|------|-----|--------------|----------|
| Юр. лицо | селект | да | `legal_entities` |
| Дата и время | datetime-local | да | — |
| Площадка отгрузки | селект | да | `loading_sites` |
| Площадка доставки | селект | да | `destination_sites` |
| Название фракции | селект | да | `fractions` |
| Объём, т | селект | да | `volumes` |
| Номер авто | селект | да | `vehicles` |
| Комментарий | textarea | нет | — |
| Кнопка «Сохранить» | — | — | создаёт заявку |

- Юрлицо не связано с номером авто.
- После сохранения — тост «Заявка сохранена» и очистка формы.
- Публичный `POST /api/orders` защищён rate-limit (30 заявок / 10 мин).

## 4. Номер заявки

Только цифры, без разделителей. Формируется из полной даты-времени и цифр номера авто:

```
<YYYYMMDD><HHMMSS><цифры_номера_авто>
пример: дата 2026-10-21 14:30, авто А123БВ777 → 20261021143000123777
```

- Буквы из номера авто вырезаются, остаются цифры.
- При коллизии добавляется числовой суффикс (`...1`, `...2`).
- При редактировании даты/времени или авто номер пересчитывается.

## 5. Админ-панель (`/admin`)

- **Список заявок** — таблица, сортировка по дате ↓. Все колонки заявки.
- **Фильтры:** номер авто, юрлицо, конкретная дата, период (от–до), сброс.
- **Редактирование** заявки (модалка) и **удаление**.
- **Управление справочниками** (вкладка): добавить, переименовать, включить/выключить,
  удалить. Удаление значения, используемого в заявках, запрещено (только отключение).
- **Экспорт в Excel** (`.xlsx`, все колонки, с учётом активных фильтров).

## 6. Справочники

| Справочник | Поле | Таблица |
|-----------|------|---------|
| Юр. лица | `name` | `legal_entities` |
| Площадки отгрузки | `name` | `loading_sites` |
| Площадки доставки | `name` | `destination_sites` |
| Фракции | `name` | `fractions` |
| Объёмы (т) | `value`, `unit` | `volumes` |
| Номера авто | `number` | `vehicles` |

Общие поля: `is_active`, `sort_order`, `created_at`. Заполняет только админ.

## 7. Модель данных

```
legal_entities    id, name, is_active, sort_order, created_at
loading_sites     id, name, is_active, sort_order, created_at
destination_sites id, name, is_active, sort_order, created_at
fractions         id, name, is_active, sort_order, created_at
volumes           id, value, unit, is_active, sort_order, created_at
vehicles          id, number, is_active, sort_order, created_at
shipment_orders   id, order_number UNIQUE, legal_entity_id, order_at, loading_site_id,
                  destination_site_id, fraction_id, volume_id, vehicle_id, comment,
                  created_at, updated_at
```

## 8. API

Публично: `GET /api/dictionaries/:type`, `POST /api/orders`.
Только админ (JWT): CRUD справочников, список/фильтры/редактирование/удаление заявок, экспорт.

```
GET    /api/dictionaries/:type            # type: legal-entities|loading-sites|destination-sites|fractions|volumes|vehicles
POST   /api/dictionaries/:type            # admin
PUT    /api/dictionaries/:type/:id        # admin
DELETE /api/dictionaries/:type/:id        # admin

POST   /api/orders                        # публично
GET    /api/orders?vehicle_id=&legal_entity_id=&date=&date_from=&date_to=&page=&limit=   # admin
GET    /api/orders/:id                    # admin
PUT    /api/orders/:id                    # admin
DELETE /api/orders/:id                    # admin
GET    /api/orders/export                 # admin, xlsx
```

## 9. Фронтенд

- `/` — публичная форма (`OrderFormSection.vue`).
- `/admin` — за авторизацией: `OrdersTable`, `OrdersFilterBar`, `OrderEditModal`,
  `DictionariesManager`.
- Стек: Vue 3 + Vite + Pinia + Vue Router + Tailwind; Express + Knex + better-sqlite3.

## 10. Вне рамок (пока)

Статусы заявок не используются.
